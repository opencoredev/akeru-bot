# Review usage

Open Usage from the sidebar to see how much of each connected subscription is
left. It uses the accounts from Settings → Providers: ChatGPT, Claude, Grok,
and Kimi For Coding. Disconnected accounts are hidden.

Each row is a cap (5-hour, weekly, or plan) with percent left and when it
resets. Usage reloads every five minutes. Change that interval in
Settings → General. The refresh button reloads immediately.
