# Plugin directory

The live `entries/` tree is the plugin catalog. Each `entries/<id>/` directory owns one `plugin.json` manifest plus official `logo.svg` and `logo-dark.svg` assets. The loader preserves the manifest ID as `builtin-<id>` and orders featured entries by `featuredRank`.

An available entry needs a real HTTPS URL or stdio command. A blocked vendor entry uses an unavailable transport, `approval-pending` connection and catalog status, and a concrete blocker. Permission declarations must name each consequential approval class that the plugin can require.

Run the catalog validator before review:

```sh
bun run plugins:check
```
