Bot work that failed or was canceled can be retried once as new work, and a bot can keep work running after the reply that started it stops. Work cards on mobile now offer Let it finish, Cancel, and Try again too. A routine can now hand each run to another bot: pick it under **Done by** in the routine form, and the run settles with that bot's work. Bots that cannot take handed-off work show as unavailable in that list.
