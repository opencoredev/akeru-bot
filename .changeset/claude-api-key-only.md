Claude now connects with an Anthropic API key only. Anthropic does not allow third-party apps to offer Claude Pro or Max sign-in, so Akeru no longer offers it and no longer identifies itself as Claude Code. If you signed in with Claude Pro or Max before, Akeru deletes that login when it starts, and the Claude row and any bot that uses Claude say to add an API key in Settings > Providers. Claude no longer shows plan limits on the Usage page.
